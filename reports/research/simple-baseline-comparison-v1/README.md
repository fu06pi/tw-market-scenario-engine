# 簡單基準比較 v1

已建立 4 個價格基準、5 個純方向基準，並加入原研究的拆分／直接收盤模型作凍結參考。所有方法都在相同的 TAIEX 179 日、TX202603 32 日評分，成功覆蓋全部觀測日期，沒有略去失敗日。

這些期間已被前次歷史研究看過，本表只作可比較的基準盤點，**不是新的獨立未見測試，也不作正式達標證明**。行情的歷史發布時間仍未核實，TX 為低流動性單一遠月合約。

## 價格比較

收盤 MAE 單位為 bp，1bp＝0.01 個百分點；方向以 ±5bp 定義平盤區。價格誤差與方向命中率分開解讀。

| 方法 | TAIEX 收盤 MAE | TAIEX 收盤方向 | TX 收盤 MAE | TX 收盤方向 |
|---|---:|---:|---:|---:|
| 前收不變 | 141.410 | 1.68% | 91.119 | 3.13% |
| 歷史平均 | 140.328 | 55.87% | 85.404 | 65.63% |
| 沿用前日報酬 | 193.834 | 54.19% | 127.557 | 59.38% |
| 固定 20 日平均 | 141.553 | 51.96% | 92.952 | 34.38% |
| 凍結直接收盤 Ridge | 141.325 | 48.04% | 88.781 | 59.38% |
| 凍結拆分 Ridge | 141.214 | 49.72% | 92.169 | 53.13% |

前收不變的價格預測是「收盤不動」，因此只有實際平盤日會命中方向；低方向命中率不代表其價格 MAE 一定差。純方向猜漲則沒有點位，不可替它填價格誤差。

所有價格方法另提供 O/H/L/C 的點數／bp MAE、RMSE、gap／body 誤差與方向混淆矩陣，見 [summary.json](summary.json)。

## 驗證期預選基準

| 市場 | 價格基準：驗證期最低收盤 MAE | 方向基準：驗證期最高收盤命中率 |
|---|---|---|
| TAIEX | 歷史平均 | 一直猜漲 |
| TX202603 | 前收不變 | 一直猜跌 |

TX 的驗證期一直猜跌為 57.14%，一直猜漲為 42.86%，因此預選猜跌。到了後續評估期，猜漲為 65.63%、猜跌為 31.25%；仍保留驗證期的選擇，不事後改成猜漲。價格同理，不因看到 TX 評估期歷史平均的 MAE 更低，就把它改稱當時已選定的基準。

這能區分基準的穩定性、方向偏向變化與價格預測能力，而不把看過答案後的最佳方法當成事前證據。

## 缺資料項目

原夜盤固定權重基準已保留，盤前接口會驗證特徵時間；但這批快取缺少可對齊的台指夜盤、SOX、TSMC ADR 歷史特徵，所以列為 **unavailable**，沒有以零值補入，也不與價格資訊集混合排名。它只有開盤方向，不宣稱能預測收盤。

## 重現與檢查

從 repo 根目錄，準備原研究計畫與具有使用權限的快取後執行：

```bash
python scripts/compare_simple_baselines.py \
  --reference reports/generated/historical-validation-v1 \
  --output reports/generated/simple-baseline-comparison-new
python -m pytest -q
python -m ruff check src tests scripts/compare_simple_baselines.py
```

`--output` 必須是新目錄。原參考預測與實際值會先對照共同日期與來源，再重算分數；缺日、重複日或實際值不一致會拒絕，沒有靜默改用較小交集。

- [plan.json](plan.json)：固定方法、20 日視窗、共同暖機、政策、資訊集、已看過評估期標記及指紋。
- [TAIEX-selection.json](TAIEX-selection.json)、[TX202603-selection.json](TX202603-selection.json)：評估前寫入的驗證期選擇。
- [summary.json](summary.json)：所有方法的分項結果、覆蓋率與失敗數。
- [manifest.json](manifest.json)：彙總檔案 SHA-256；逐日資料只存於本地忽略追蹤目錄。
- [規則與接口](../../../docs/methodology/SIMPLE_BASELINES.md)：每個基準的定義與盤前資料契約。

共 **87 項測試通過**，包含價格一致性、20 日視窗、純方向不捏造點位、盤前時間與合約隔離、缺夜盤特徵、完整日期對照、失敗樣本分母及零誤差基準的處理。
