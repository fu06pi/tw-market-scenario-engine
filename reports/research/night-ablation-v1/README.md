# 夜盤資料配對驗證：收盤有改善，仍未優於簡單夜盤基準

本次實際取得期交所 22 個月的 TX 日盤／夜盤 CSV，比較同一個價格研究模型加入夜盤報酬前後的結果。兩版使用相同日期、標籤、過去訓練樣本、alpha=0.1、影線估計與盤中模型；**只在開盤模型增加一項夜盤報酬**。

TAIEX 與按盤前規則選月的 TX，各完整覆蓋 2026-01-02～2026-09-30 的 179 個評估日。TAIEX 收盤 MAE 降低 22.19%，TX 降低 28.76%；但 TAIEX 開盤 MAE 惡化 3.65%。因此不能宣稱所有目標均改善。

這是回溯研究。歷史發布時間仍未核實，TAIEX 的價格評估區間先前也已看過，**不是新的獨立未見測試或實盤前向績效**。未改動原晨報、歷史預測或每日排程。

## 資料與時間口徑

- 官方來源：[期貨每日交易行情下載](https://www.taifex.com.tw/cht/3/dlFutDailyMarketView)，以官方表單向 `futDataDown` POST，逐月查詢 2024-12～2026-09，共 22 檔。CSV 同時含一般／盤後交易，依「交易時段」欄分開，不能只靠請求參數猜測時段。
- [期交所盤後交易介紹](https://www.taifex.com.tw/cht/4/aHIntroduction) 明定 TX 夜盤為 15:00～次日 05:00，交易歸屬下一個一般交易時段。CSV 的夜盤交易日 D 對應 D 的日盤，不把日曆夜盤開始日直接當作 D。
- 星期五夜盤在星期六 05:00 結束，交易日通常屬星期一，並不是星期一 05:00 才結束。保存截至 D 日 08:30 的資料年齡，週末／假日不填成新行情。
- 月份選擇事先固定：在 D 已完成、正成交量的夜盤月合約中選最早 YYYYMM，排除週契約與價差。只用截止前可知的夜盤資料，不用 D 日盤成交量或事後主力資訊。
- 夜盤報酬＝`10000 × (夜盤最後成交價／同合約前一日盤最後成交價 − 1)`。缺同合約前收就排除，不換別的合約，不用結算價補值。
- TX 目標及前日特徵也使用當天被選合約自己的歷史價格；換月不形成跨合約報酬。TAIEX 的指數前收與 TX 夜盤參考價分開，不把期現絕對價差當成指數跳空。

曾查核 2025-12-29、2026-06-18、2026-09-14 的官方夜盤 HTML：最終成交價及夜盤開始日均與 CSV／對齊規則一致，涵蓋週一及換月後案例。見 [source-crosscheck.json](source-crosscheck.json)。這些查核證實來源及交易時段對應，不能證明所有歷史 bulk CSV 都在 08:30 前發布。

每檔保存原始 bytes、查詢條件、fetched_at 與 SHA-256。`available_at` 保持 None，`historical_availability_verified=false`，不把現在下載時間或推定的 05:00 結束時間冒充歷史發布時間。

## 看結果前固定的實驗

原 [plan.json](plan.json) 在評分前保存，沒有修改資料、參數或視窗追求評估期成績。

| 項目 | 固定設定 |
|---|---|
| 訓練 | 嚴格較早的共同樣本，初始訓練至 2025-09-30 |
| 驗證 | 2025-10-01～12-31；此實驗不再搜尋參數 |
| 評估 | 2026-01-02～09-30，兩標的各 179 日 |
| 更新 | 每天擴展訓練，只使用當天之前的共同標籤 |
| alpha | 兩版均固定 0.1，不重新選參數 |
| 開盤模型原特徵 | 前日跳空、前日收盤報酬 |
| 開盤新增特徵 | 一項 night_return_bps |
| 盤中模型 | 兩版相同：前日開收報酬、前日振幅 |
| 影線 | 兩版相同的過去非負 log 影線平均 |
| 方向標籤 | ±5bp 中性帶 |
| 主要研究目標 | 開盤 MAE 至少降低 5%，配對區塊區間下界大於零 |
| 次要研究目標 | 收盤 MAE 至少降低 5%，O/H/L 各不惡化超過 5%（相對無夜盤版） |

TAIEX 共 422 個原始目標日，最初兩日缺少指數前期特徵而排除，保留 420 列；驗證期前 179 列。TX 共 422 列，驗證期前 181 列。兩標的驗證期各 62 日，評估期各 179 日全部成功，無缺漏或模型失敗；所有來源排除原因另列 summary。盤中頭在兩版所有比較日的 log 預測差異最大值均為 **0**。

## 配對評估結果

MAE 單位 bp，1bp＝0.01 個百分點。

| 標的／方法 | 開盤 MAE | 開盤方向 | 收盤 MAE | 收盤方向 |
|---|---:|---:|---:|---:|
| TAIEX 無夜盤 | 38.700 | 48.60% | 141.214 | 49.72% |
| TAIEX 加夜盤 | 40.111 | 83.24% | 109.876 | 72.63% |
| TAIEX 夜盤直推基準 | 85.363 | 79.89% | 103.262 | 74.30% |
| TX 事前選月、無夜盤 | 125.569 | 44.13% | 154.030 | 43.02% |
| TX 事前選月、加夜盤 | 46.046 | 87.71% | 109.728 | 72.07% |
| TX 事前選月、夜盤直推基準 | 43.678 | 88.83% | 106.686 | 73.18% |

「夜盤直推基準」在計畫中已列入：開盤 log 報酬直接採夜盤報酬，盤中採過去平均 log body，影線使用相同方法，沒有擬合夜盤係數。它也使用可比較的共同日期與資料。

加夜盤相對無夜盤的誤差改善率與配對時間區塊 bootstrap 95% 區間（5 日區塊、2,000 次、種子 20261104）：

| 指標 | 改善率 | 95% 區間 |
|---|---:|---:|
| TAIEX 開盤 | −3.65%（惡化） | −26.53%～+11.30% |
| TAIEX 收盤 | +22.19% | +17.13%～+26.99% |
| TX 開盤 | +63.33% | +57.63%～+68.19% |
| TX 收盤 | +28.76% | +21.05%～+35.81% |

主要的「開盤幅度實用改善」目標只在 TX 通過。TAIEX 雖然開盤方向明顯提升，開盤幅度誤差卻沒有改善；不能把方向命中當成點位準確。

收盤與 O/H/L 的條件式價格門檻，相對無夜盤版在兩標的都通過：TAIEX O/H/L 誤差變化為 +3.65%／−28.29%／−22.32%；TX 為 −63.33%／−36.27%／−37.15%。**這不等於完整驗收通過**：加入夜盤的回歸版收盤 MAE 仍比預先列入的簡單夜盤基準差 6.41%（TAIEX）、2.85%（TX），且資料發布時點與獨立未見驗證仍有缺口。

## 可支持的決策與限制

目前支持在相同資料及模型條件下，繼續研究夜盤資訊對收盤的增益；不支持直接宣稱 TAIEX 開盤幅度已改善，或較複雜回歸模型已超過夜盤簡單基準。

TX 此次是按盤前可知規則選出的逐日月合約，每天都用自身前收。它不是先前只有 TX202603 的低流動性遠月實驗，因此不能將兩次實驗的百分比直接當成同一模型前後改善。

來源逐筆歷史發布時間沒有證明，採「夜盤已完成，且假設該成交資訊能在 08:30 前使用」的回溯假設；bulk CSV 本身的發布可能晚於盤前。標準交易時段的特殊停市例外也未逐日獨立核驗。價格評估區間已看過，不屬新的獨立前向證據。未產生新正式盤前快照、未改舊紀錄，亦未切換 V0／Sheet／每日排程；區間校準與成本後交易表現未驗證。

## 重現

先按 [plan.json](plan.json) 的輸入指紋準備有權限的 TAIEX 快取，再取得官方 TX 月檔：

```bash
python scripts/fetch_taifex_history.py --start 202412 --end 202609
mkdir -p reports/generated/night-ablation-rerun
cp reports/research/night-ablation-v1/plan.json reports/generated/night-ablation-rerun/plan.json
python scripts/run_night_ablation.py --output reports/generated/night-ablation-rerun
python -m pytest -q
python -m ruff check src tests scripts/run_night_ablation.py scripts/fetch_taifex_history.py
```

輸入版本必須吻合，不會自動更新來源或覆寫已有結果。下載按月限制、三個並行請求、不可覆寫快取並可續跑；原 CSV 與逐日實際值留在 Git 忽略追蹤目錄。當月未完成的資料應使用新的來源版本，不把不可覆寫月快取當成即時 feed。

- [summary.json](summary.json)：完整 OHLC 指標、方向混淆矩陣、缺漏、週末／換月分組、不確定性與版本。
- [manifest.json](manifest.json)：公開彙總指紋與本地逐日結果位置。
- [source-crosscheck.json](source-crosscheck.json)：官方 HTML 與 CSV 的案例核對。

共 **107 項測試通過**，新增 CSV 欄位／編碼、日夜分離、最後成交與結算區別、同合約換月參考、週末日期、截止、不可覆寫快取、當日夜盤特徵隔離、未來標籤隔離與配對日期一致性等檢查。加強快取／完整性檢查後，以相同計畫重跑，所有預測指標與首次結果完全一致。
