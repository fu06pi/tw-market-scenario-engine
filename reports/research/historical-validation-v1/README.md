# 歷史資料驗證：尚未支持改善

本次使用已保存的非合成行情，執行時間順序的回溯比較。測試對象是 **僅使用前一交易日 OHLC 特徵的拆分 Ridge 研究版**，沒有夜盤、海外市場、新聞或盤中即時資訊。不能將這些數字當成原晨報或含夜盤新版的完整績效。

結果：TAIEX 與 TX202603 均未通過事前固定的價格誤差門檻。沒有以這批最終測試結果繼續選參數，也未切換任何正式輸出。

## 固定切分與方法

計畫於看測試結果前保存，見 [plan.json](plan.json)。

| 資料 | 訓練 | 驗證／選模 | 保留測試 |
|---|---|---|---|
| TAIEX | 2025-01～09，179 個可用訓練樣本 | 2025-10～12，62 日 | 2026-01-02～09-30，179 日 |
| TX202603 | 2025-07～10/15，69 個可用訓練樣本 | 2025-10/16～11/14，21 日 | 2025-11/17～12/31，32 日 |

每個目標日用嚴格較早的標籤逐日擴展訓練；特徵只取前一觀測交易日的跳空、收盤報酬、開收報酬與振幅。gap／body 各用不同特徵，獨立標準化與擬合；數值核心與盤前 forecaster 共用。影線採過去非負 log 影線的平均。

比較零報酬、歷史平均與直接收盤 Ridge。正則化只搜尋 0.1、1、10；候選參數、直接模型參數與最強價格基準均按驗證集收盤 bp MAE 選定，在最終測試前寫入 locked-selection 檔案。兩市場的拆分 alpha 均選為 0.1。

「一直預測上漲」是額外的固定方向對照；價格基準則由驗證集的 MAE 選定，兩者用途不同。沒有看完測試後改挑最有利的價格基準。

收盤 MAE 改善率的配對時間區塊 bootstrap（5 日區塊、2,000 次、種子 20261103）95% 區間：

- TAIEX：−1.95%～+0.80%。
- TX202603：−11.59%～+17.19%。

未支持穩定改善；兩市場的點估也未達收盤 MAE 改善至少 5% 的門檻。TAIEX 開盤 MAE、TX 低點 MAE 另超過不得惡化 5% 的限制。

## 資料品質與可解讀範圍

TAIEX 使用 TEJ trial 的 2025 年 243 筆與 TWSE 官方下載快取的 2026 年 179 筆。兩來源在 2025 年 12 月重疊的 22 日 OHLC 全數一致後才接續資料；日期無重複，OHLC 均為有限正值且關係一致。開始的兩列用來建立前期特徵，沒有填造交易日或零報酬。

TX 資料只有 **TX202603 單一遠月合約**，不代表連續近月台指期；124 筆資料的成交量中位數只有 14 口，121 筆低於 100 口。這會限制價格代表性，不能將 32 日結果外推成近月交易成效。每一列都在同合約內計算報酬，沒有跨月價差拼接。

所有來源都明示歷史發布時間未經驗證。本次保留原始 available_at，不把它改成過去時間；回溯研究單獨採用「前一個已完成觀測交易日的 OHLC，在下一觀測交易日盤前可用」的假設。**結果是此假設下的歷史比較，不是已驗證的盤前前向績效。** 訓練、驗證與測試各階段都受同一限制。

此外，沒有區間校準、名義 80% 區間或完整兩標的正式驗收；沒有成本後交易測試，也不能由預測命中率推論獲利。

## 重現與產物

專案環境、已授權取得的來源快取與已保存計畫就緒後，從 repo 根目錄執行：

```bash
python -m pytest -q
python -m ruff check src tests scripts/run_historical_validation.py
# 使用全新的輸出目錄，不覆寫舊實驗：
mkdir -p reports/generated/historical-validation-rerun
cp reports/research/historical-validation-v1/plan.json reports/generated/historical-validation-rerun/plan.json
python scripts/run_historical_validation.py --output reports/generated/historical-validation-rerun
```

輸入檔 SHA-256 必須與計畫一致，不會自動使用另一批行情。資料不在 Git 中發佈，需使用具有權限的快取；逐日預測與實際 OHLC 也只保留在忽略追蹤的 `reports/generated/historical-validation-v1/daily-private.json`。

- [summary.json](summary.json)：兩市場指標、八項 OHLC 誤差、方向混淆矩陣、每月／前日波動分組、失敗數及不確定性。
- [TAIEX-locked-selection.json](TAIEX-locked-selection.json)、[TX202603-locked-selection.json](TX202603-locked-selection.json)：驗證集選模與全部嘗試。
- [manifest.json](manifest.json)：程式與公開彙總產物的 SHA-256。

原有 55 項測試及新增的未來價格擾動、當日目標隔離、合約混用與配對 bootstrap 檢查，合計 **63 項通過**。實驗 CPU 執行約 2.36 秒，程序峰值記憶體約 135MB，未購買運算。

目前的決策是保留原流程，將此候選維持為研究版。下一輪可加入具有可驗證時間的夜盤／海外資訊或修改假設，但本次最終測試集已看過，後續改善結論須使用新的未見資料或事前固定的額外驗證流程。
